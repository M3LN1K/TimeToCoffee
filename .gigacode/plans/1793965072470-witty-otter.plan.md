# Code Review: TimeToCoffee Laravel Project

## КРИТИЧЕСКИЕ (блокируют запуск / ломают функционал)

### 1. Дублирование маршрута `/` в `routes/web.php`
**Файл:** `routes/web.php`
**Проблема:** Два маршрута на `/` с одинаковым именем `home` — замыкание и контроллер. Второй перезаписывает первый, первый — мёртвый код.
**Решение:** Удалить замыкание, оставить только `PageController@index`.

### 2. Неправильные namespace (нижний регистр) — PSR-4 не работает
**Файлы:**
- `app/Models/User.php` → `namespace app\Models;` (должно быть `App\Models`)
- `app/Models/Event.php` → проверить namespace
- `app/Providers/AppServiceProvider.php` → `namespace app\Providers;` (должно быть `App\Providers`)
- `database/seeders/DatabaseSeeder.php` → `namespace database\seeders;` (должно быть `Database\Seeders`)
- `database/factories/UserFactory.php` → `namespace database\factories;` (должно быть `Database\Factories`)
- `database/migrations/0001_01_01_000001_create_cache_table.php` → `namespace pablic\database\migrations;` (опечатка + неправильный namespace)
**Проблема:** PSR-4 в `composer.json` использует заглавные буквы (`App\`, `Database\`, `Tests\`). Все use-импорты тоже в нижнем регистре.
**Решение:** Привести все namespace и use-импорты к верхнему регистру первого символа.

### 3. Отсутствуют `.env` и `.env.example`
**Проблема:** Без `.env` Laravel не запустится. Скрипты `composer.json` ссылаются на `.env.example`, но его нет.
**Решение:** Создать `.env.example` со стандартным набором переменных Laravel.

### 4. Booking и Checkout формы отправляют на несуществующие PHP-файлы
**Файлы:** `public/js/booking-form.js` → `/booking_handler.php`, `public/js/checkout.js` → `/submit_order.php`
**Проблема:** Это raw PHP-файлы, не Laravel-маршруты. Файлы не существуют. Формы полностью неработоспособны.
**Решение:** Создать Laravel-маршруты и контроллер для обработки бронирований и заказов.

### 5. Нет CSRF-токена в fetch-запросах
**Файлы:** `booking-form.js`, `checkout.js`
**Проблема:** POST-запросы без CSRF-токена будут отвергнуты Laravel.
**Решение:** Добавлять токен в headers и в meta-tag в layout.

### 6. EventResource.php (файл) и EventResource/ (директория) конфликтуют
**Проблема:** Filament `discoverResources()` может не загрузить ресурсы корректно из-за конфликта имени.
**Решение:** Переименовать или переструктурировать.

## ВЫСОКИЙ СЕРЬЁЗНОСТЬ

### 7. EventController полностью пустой
**Файл:** `app/Http/Controllers/EventController.php`
Все 7 REST-методов содержат только `//`. Не зарегистрирован в роутах.
**Решение:** Либо удалить, либо реализовать.

### 8. Модель Event без `$fillable`
**Файл:** `app/Models/Event.php`
**Проблема:** Mass assignment unprotected — любой атрибут может быть установлен извне.
**Решение:** Добавить `$fillable = ['title', 'type', 'description', 'price', 'schedule', 'is_active', 'slug'];`.

### 9. Windows-слэши в путях изображений
**Файлы:** `resources/views/home/about.blade.php`, `app.blade.php`, `history.blade.php`, `hero.blade.php`
**Проблема:** `images\gallery\about-interior3.jpeg` — сломается на Linux-сервере.
**Решение:** Заменить `\` на `/`.

### 10. ID mismatch в menu-tabs.js
**Файл:** `public/js/menu-tabs.js`
**Проблема:** JS ищет `${tabName}-tab`, но Blade генерирует `{{ $type }}` (без `-tab`).
**Решение:** Синхронизировать ID в JS и Blade.

### 11. `welcome.blade.php` — мёртвый код
**Файл:** `resources/views/welcome.blade.php`
**Проблема:** Неиспользуемая стандартная страница Laravel (~2000 строк Tailwind CSS).
**Решение:** Удалить.

### 17. Дублирование JS: `tabs.js` и `menu-tabs.js` делают одно и то же
